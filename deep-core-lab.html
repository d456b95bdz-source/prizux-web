PRIZUX

Relationship Lab

Train Deep Core using structured numerical samples.
Each sample maps multiple X values to a single Y value.

Training Data
Each training sample follows this format:
(X, X, X, …) → Y

Multiple samples can be added:
(X₁, X₂, X₃) → Y, (X'₁, X'₂) → Y'
Prediction
Enter a new set of X values to predict Y.
