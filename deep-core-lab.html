Deep Core Lab

Deep Core learns numerical relationships.
X values are the inputs you give to the AI, and Y values are the results you want it to predict.

Input format:
Each line is one data sample.
X supports multiple values per row (space separated).
Y must have exactly the same number of lines as X.

Example:
If you want to predict height using foot size and hand size: 

X:
26 18
27 19
28 20

Y:
170
175
180
